# Path Beaters '26

- `index.html`: the original Spanish Peaks loop site.
- `options/`: the options board comparing alternative trips.
- `bigboulder/`: the chosen trip, Big Boulder Lakes in the White Clouds. 3D satellite map, week strip, elevation profiles, and the NWS forecast at the trailhead and both camps. The forecast refreshes live in the browser; refresh the saved fallback with `python3 bigboulder/fetch_wx.py`.
